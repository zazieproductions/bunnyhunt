## 5. What is actually left to try — ranked

1. **Amazon B0CDZYFMHC, but attack it differently.** Open the listing and click **"Other sellers" / "New & Used from…"** — the seller who cancels you is often not the only one holding the buy box. Then **message the seller directly** and ask one plain question: *is this discontinued?* A Chinese dropshipper will usually answer honestly, and a "yes" saves you months of re-ordering. Any cancellation on an in-stock item is covered by the A-to-z Guarantee and worth one short message to Amazon support.
2. **Buy from the source via a Chinese agent** — Superbuy, CSSBuy or Sugargoo — with these keywords, which are the real trade terms for this pose:
   - `趴趴睡觉兔子` (sprawled-asleep rabbit) ← best term found
   - `眯眼小兔子` (squinting/closed-eye rabbit)
   - `揣手小兔子` (paws-tucked rabbit)
   - `垂耳小兔子` (lop-eared rabbit)
   - `兔子树脂摆件 DIY配件` (resin rabbit ornament, DIY parts)
   - `15款复活节小兔子` (15-style Easter rabbit set)
   - Sowewhere in the ¥0.10–0.94 range, MOQ 2–100. Order two or three.
3. **Set saved-search alerts on eBay and Mercari.** This is now a discontinued item, so what you're hunting is dead stock and secondhand — exactly what alerts are for. Search terms: `resin rabbit car ornament`, `bunny dashboard ornament`, `micro landscape rabbit figurine`.
4. **Send the supplier enquiry** from `who-makes-your-bunny.html` to 5–6 named workshops. A factory that owns the mould often still has a carton in the back, or can run a small batch. The four questions in that message are built to unmask a trader pretending to be a factory.
5. **Repair the one you have.** With the mould out of production, this is no longer the fallback — it's a legitimate main option. Gel cyanoacrylate (not liquid superglue, which wicks into cracks and fogs glossy resin), held 30 seconds, plus a hidden pin if a limb is involved.

**Buy two if you ever find one.** That is the real fix for "it broke and there was nothing left".

## 6. Research toolkit — what works, what doesn't

Worth keeping for any future search, because half these engines failed silently.

### Works

- **AliExpress photo extraction:** load `aliexpress.us/item/<ID>.html` in a page renderer. The body is captcha-walled, but **gallery thumbnails leak** as `ae-pic-a1.aliexpress-media.com/kf/<hash>.jpg_960x960q75.jpg`. Download and look. This is how every AliExpress rejection above was made, and it's the difference between reading a title and seeing the rabbit.
- **Yandex reverse-image by URL:** give it a public image URL. Amazon images are live and predictable — `m.media-amazon.com/images/I/<imageID>.jpg`; AliExpress — `ae01.alicdn.com/kf/<hash>.jpg`. This pass found the German Amazon title, the Joom ID, the Lyvi and ChinaStock mirrors, and the "baking cake decorative ornaments" title variant.
- **Direct image download + PIL comparison.** Never trust a title. Titles are copy-pasted between unrelated products constantly.
- **Amazon product pages** render via both curl and the page renderer; **Amazon search pages** only via the renderer.
- **`tmpfiles.org`** for uploading a local image when you need a public URL.

### Dead — don't retry

| Engine / site | Failure |
|---|---|
| **Google Lens** (`uploadbyurl`) | HTTP 500 |
| **Bing Visual Search** | Silently degrades to a plain text query — looks like it worked, doesn't |
| **TinEye** | Cookie wall only, no results |
| **Baidu 识图** | Refuses remote URLs; direct upload returns `{"status":1,"msg":"Reject"}` |
| **Sogou 识图** | No results / server error |
| **Yandex "similar images"** | JS-only, returns an empty grid |
| **Wildberries** | Browser check page |

### Confirmed working Chinese search surfaces

- `yiwugo.com/search/sproduct.html?q=…` — renders without login, gives stall numbers and phone numbers
- `chinagoods.com/store/goodsdetail/<id>` — Yiwu official: seller, brand, stock, price
- Taobao tag pages (`mobile-phone.taobao.com/chanpin/<hash>.html`) — best source of authentic Chinese SKU vocabulary without opening individual items
