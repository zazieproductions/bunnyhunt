Paste a link — get a verdict

A local page. Nothing is sent anywhere, nothing is fetched — it just reads the shape of the URL and the number inside it against everything already checked. Built 2 November 2026.

    What it checks

    • Is there an AliExpress item ID in the URL? It hunts for 100500… / 3256… anywhere in the string and reports it.
    • Is there a scraper prefix glued in front of it? 88, pid99, aid_8881500, infobox_, p-, p-88, tovar- and friends.
    • Is the domain a known mirror? A standing list of the ones already seen, plus anything with a junk-prefix pattern.
    • Is that ID already dead? A list of the item numbers already confirmed delisted — the big one being 1005001333292108, which now resolves to a different product on AliExpress itself.
    • Is the domain a real marketplace? Amazon, eBay, Etsy, Walmart, Temu, AliExpress item, Yiwugo, Ozon, Joom, Mercado Libre, and so on — those get a "worth a look" instead of a dismissal.

    It cannot know about a marketplace it has never heard of. If a link comes back unknown, that's not a green light — it means the URL shape told us nothing, and you fall back to the five questions below.

    The five questions, for anything the checker can't settle

    0 of 5 — you need all five before money moves.

    Anything under five is not a purchase option, however real the page looks. That test would have caught every mirror you've been sent so far: none of them has a cart.
